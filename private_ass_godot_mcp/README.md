# GAT — Godot Agent Toolkit

A headless Godot IDE for AI agents. Exposes the entire Godot 4.6 engine as a queryable knowledge graph through MCP tools — classes, methods, properties, signals, inheritance, constants, enums, and full project introspection. No Godot editor required.

## What It Does

- **Engine reflection** — query any Godot class, method, property, or signal with full inheritance resolution (22,095 nodes, 54,966 edges)
- **Project introspection** — load a Godot project and inspect scene trees, scripts, signal connections, node types
- **Validation** — check property values, node paths, signal connections, and scene integrity before editing
- **Documentation search** — FTS5 search across 1,078 class docs and 557 tutorials

## Setup

### Prerequisites

- Python 3.13+
- FastMCP 3.2.0 (`pip install fastmcp`)

### Configure MCP

Add to your `.mcp.json` (project-level or global):

```json
{
  "mcpServers": {
    "gat": {
      "type": "stdio",
      "command": "C:/Python313/python.exe",
      "args": ["-m", "gat.server"],
      "env": {
        "PYTHONPATH": "/path/to/private_ass_godot_mcp"
      }
    }
  }
}
```

Replace paths with your local paths. On Linux/Mac use `/usr/bin/python3` and the appropriate PYTHONPATH.

### Engine Schema

The `data/engine_schema.json` file (8.6MB) is generated by the Godot editor plugin at `addons/gat/classdb_dump.gd`. It contains the complete ClassDB extraction from Godot 4.6:

- 1,034 classes, 11,701 methods, 4,091 properties, 370 signals, 4,327 constants, 572 enums

On first server start, this schema is automatically loaded into a SQLite graph database at `data/gat.db`. Subsequent starts reuse the existing database.

## Tools

All tools are available as `mcp__gat__*` in Claude Code after connecting. 20 tools total across 4 categories.

### Engine Query Tools (10)

| Tool | Description |
|------|-------------|
| `get_class` | Full class definition with all members and inheritance |
| `find_inheritance` | Inheritance chain from a class up to Object |
| `find_children` | All classes that inherit from a given class |
| `search_engine` | Fuzzy search for classes, methods, properties, signals, constants, enums |
| `get_method` | Method signature, walks inheritance to find it |
| `get_signal` | Signal signature, walks inheritance to find it |
| `who_has_signal` | All classes that have a signal (own or inherited) |
| `who_has_method` | All classes that have a method (own or inherited) |
| `graph_stats` | Node/edge counts by type |
| `search_documentation` | FTS5 search across Godot class docs and tutorials |

### Project Tools (6)

| Tool | Description |
|------|-------------|
| `load_project` | Scan and parse a Godot project (scenes, scripts, resources) |
| `get_project_structure` | Project overview: name, scenes, scripts, stats |
| `get_scene_tree` | Full node tree for a scene with types and signal connections |
| `get_node` | Get a specific node from a scene |
| `find_nodes_by_type` | Find all project nodes of a given engine type |
| `get_signal_connections` | All signal connections in a scene |

### Validation Tools (4)

| Tool | Description |
|------|-------------|
| `validate_property` | Check a property value against type hints (range, enum, int, float, bool) |
| `validate_node_path` | Verify a node path resolves in a scene tree |

| `validate_scene` | Full scene audit: node types, signal connections, structure |

## Usage Examples

### Engine Queries

**Get a class with all its members:**
```
get_class("CharacterBody2D")
```
Returns: name, inheritance chain, all properties, methods, signals, constants, enums (including inherited).

**Find what inherits from a class:**
```
find_children("Node2D")
```
Returns: Sprite2D, CharacterBody2D, RigidBody2D, Area2D, etc.

**Search for something:**
```
search_engine("velocity", node_type="property")
```
Returns: all properties matching "velocity" across all classes.

**Find which classes have a signal:**
```
who_has_signal("pressed")
```
Returns: BaseButton, Button, LinkButton, MenuButton, etc.

**Get a method signature:**
```
get_method("CharacterBody2D", "move_and_slide")
```

**Get full inheritance chain:**
```
find_inheritance("AnimatedSprite2D")
```
Returns: `["AnimatedSprite2D", "Sprite2D", "Node2D", "CanvasItem", "Node", "Object"]`

### Project Introspection

**Load a project:**
```
load_project("/path/to/my_game")
```
Returns: project name, version, scene count, script count, resource count, custom class names.

**Get the project structure:**
```
get_project_structure()
```

**Inspect a scene tree:**
```
get_scene_tree("main")
```
Returns: all nodes with types, parent paths, properties, and signal connections.

**Find all buttons in the project:**
```
find_nodes_by_type("Button")
```

**Get a specific node:**
```
get_node("main", "Player")
```

**List signal connections:**
```
get_signal_connections("main")
```

### Validation

**Check a property value:**
```
validate_property("Button", "flat", "true")
validate_property("Sprite2D", "z_index", "5")
validate_property("Sprite2D", "z_index", "999")
```
Returns: `{valid: true/false, errors: [...], warnings: [...]}`. Checks range bounds, enum values, int/float/bool types.

**Validate a node path:**
```
validate_node_path("main", "UI/Menu/StartButton")
```
Walks the path segments to verify each node exists.

**Validate a signal connection:**
```
validate_signal_connection("Button", "pressed", "_on_start_pressed")
```

**Full scene audit:**
```
validate_scene("main")
```
Checks all node types exist and all signal connections reference valid nodes.

### Documentation Search

**Search docs:**
```
search_documentation("CharacterBody2D collision")
```
Returns ranked snippets from 1,078 class docs and 557 tutorials.

## Architecture

```
Agent -> MCP Client -> GAT MCP Server -> GodotGraph (SQLite) -> engine_schema.json
                                     -> Project Parser -> .tscn / .gd / .tres files
                                     -> Validator -> type checks, range/enum validation
                                     -> Doc Parser -> property defaults, virtual methods
```

**Graph engine** (`gat/graph.py`) — SQLite graph with nodes + edges tables, indexed for fast traversal. Supports inheritance walking, neighbor queries, full-text name search.

**Project parser** (`gat/project_parser.py`) — Parses `.tscn` (scene files), `.gd` (GDScript), `.tres`/`.res` (resources), `project.godot` into graph nodes with relationship edges.

**Validator** (`gat/validator.py`) — Validates properties (range, enum, int, float, bool), node paths (parent chain resolution), signal connections (existence + plausibility), scene integrity, class existence, and resource references.

**Doc parser** (`gat/doc_parser.py`) — Enriches the engine graph with property defaults from documentation, virtual method flags, and inheritance cross-references.

## Known Limitations

- **Method/signal argument types not available** — Godot's ClassDB API does not expose method parameter types or signal argument types. All methods show `args: []`.
- **Signal validation is warn-only** — GDScript signals are not type-safe. `emit(true)` on `signal x(amount: int)` compiles and runs.
- **`.tscn` stores only non-default properties** — The project parser sees only properties that differ from their class defaults. Merge with ClassDB defaults for full state.
- **Documentation search requires tomb vault** — The `search_documentation` tool needs the tomb FTS5 index. Falls back gracefully if unavailable.
